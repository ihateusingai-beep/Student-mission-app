# 島民小英雄 - 香港居家學習生活優化方案

## 背景目标
協助香港中小學生建立規律生活、提升學習積極性及自我管理能力

---

## 1. 語言風格與本地化

### 需要修改的字眼

| 現有字眼 | 建議改為 | 原因 |
|----------|----------|------|
| 任務 | 待辨事項 / 今日清单 | 減少壓迫感 |
| 打卡 | 完成了 ✓ | 更正向有成就感 |
| 積分 | 星級分 / 成就值 | 減少金錢聯想 |
| 獎勵商店 | 願望清單 / 成就禮物 | 強調獎勵非交易 |
| 家長控制台 | 家長支援台 | 從監督者轉為支持者 |
| 徽章 | 成就章 | 更清晰有意義 |
| 神秘任務 | 每日挑戰 | 更有趣不神秘 |
| 排行榜 | 成就榜 | 减少竞争压力 |
| 連續達成 | 持續努力 | 更正向描述 |

### 建議用語風格
- 使用「我地一齊」而非「你必須」
- 使用「今日你可以」而非「今日你應該」
- 使用「完成後你可以得到」而非「完成先有」
- 粵語口語為主，親切自然

## 2. 功能性優化

### 核心改動

1. **視覺化進度條**
   - 每日完成度一目了然
   - 进度条颜色渐变（完成越多越绿）
   - 顯示「今日已完成 X/Y」

2. **願望清單系統**
   - 學生自己新增想要的獎勵（家長審批）
   - 顯示距離心願還差多少成就值
   - 願望達成時有慶祝動畫

3. **每日摘要**
   - 睡覺前顯示今日總結
   - 「今日你完成左5件事，好叻！」
   - 明日目標預覽

4. **家庭共享功能**
   - 家長可看到學生進度（不需即時監控）
   - 家長可以留言鼓勵
   - 學生的家長留言出現在首頁

### 新的獎勵類型

| 獎勵類型 | 範例 |
|----------|------|
| 體驗類 | 去主題公園、露營、博物館 |
| 娛樂類 | 打機時間、睇片時間 |
| 美食類 | 雪糕、快餐、餐廳 |
| 實物類 | 新文具、圖書、玩具 |
| 特權類 | 周末晚啲訓、選擇晚餐 |

## 3. 管教與溝通策略

### 家長角色重新定義

| 舊角色 | 新角色 |
|--------|--------|
| 監督者 | 支持者 |
| 裁判 |教練 |
| 管理者 | 夥伴 |

### 家長支援台功能

1. **鼓勵留言**
   - 家長可以留言
   - 「加油！」「好棒！」「今日好叻」

2. **彈性設置**
   - 家長可調整任務難度
   - 家長可新增/刪除任務
   - 家長可設定願望清單

3. **进度追蹤**
   - 每日/每週摘要電郵（可選）
   - 不需要即時監控
   - 尊重學生私隱

### 親子溝通話術建議

```
❌ 負面：「你今日乜都未做！」
✅ 正面：「我見到你今日完成左兩件事，繼續加油！」

❌ 負面：「你睇下人地幾叻」
✅ 正面：「你一定有能力做到」

❌ 負面：「做唔到就冇獎勵」
✅ 正面：「做到就可以得到你想要嘅野」
```

## 4. 行為心理學應用

### 正向強化機制

1. **小勝利原則**
   - 每次完成立即獎�
   - 顯示「+1 完成」「+5 成就值」等視覺反饋
   - 音效配合（成功音）

2. **漸進式目標**
   - 任務由少至多（由2-3個開始）
   - 完成後慢慢增加
   - 從簡單任務開始建立信心

3. **不可逆轉的成就**
   - 累計的數據（總完成次數）
   - 等級系統（Lv1 → Lv2 → Lv3）
   - 成就徽章收藏

4. **社交證明**
   - 成就榜（不排名次，顯示「你已經完成X次」）
   - 和自己比較，不和別人比較

### 流程優化建議

1. **早晨流程**
   - 起床 → 查看今日清单 → 開始第一個任務
   - 首頁顯示「早晨！今日有X件事等你完成」

2. **晚間流程**
   - 完成的最後一個任務 → 顯示今日總結
   - 家長留言功能 → 睡覺提醒

3. **週末特別任務**
   - 家人活動任務（如：幫手煮飯、和家人一齊運動）
   - 長期目標任務

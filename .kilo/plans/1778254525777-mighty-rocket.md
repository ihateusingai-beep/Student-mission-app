# 島民小英雄 - Comprehensive Bug Fix Plan

## Executive Summary

After thorough code review, **45 bugs** identified across stores, screens, components, and services. Issues range from critical data loss to cosmetic UI glitches.

---

## Critical Bugs (P0 - Data Loss / Functionality Breaking)

### 1. **Ability XP Not Persisted** — `gameStore.ts:207-212`

```typescript
updateAbility: (category: string, points: number) => {
  const { abilities } = get();
  if (abilities[key]) {
    const newValue = Math.min(abilities[key].value + points, abilities[key].max);
    set({ abilities: { ...abilities, [key]: { ...abilities[key], value: newValue } } });
    storage.saveAbilities(abilities);  // BUG: saves OLD abilities, not updated
  }
},
```

**Problem:** `storage.saveAbilities(abilities)` captures the old `abilities` object from closure before `set()` updates state.

**Fix:** Save after set: `set({ abilities: newAbilities }); storage.saveAbilities(newAbilities);`

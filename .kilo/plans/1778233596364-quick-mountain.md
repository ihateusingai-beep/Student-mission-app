# 島民小英雄 - 健康成長版優化計劃書（修訂版）

## 方針調整確認

| 用戶反饋 | 響應 |
|---------|------|
| 不需要遊戲模式 | 移除戰鬥系統、 Roguelike 等內容 |
| 不想另類沉迷 | 避免 Dark Patterns，不添加疲勞激勵、連續登入獎勵、限量商品倒計時等 |

### 核心原則
1. **健康優先** - 設有使用時間提示，不激勵過度使用
2. **家長可控** - 所有獎勵需家長確認發放
3. **非遊戲化** - 專注習慣養成而非沈迷機制

---

## 推薦功能清單

### MUST（核心需求）
- [ ] **家長獎勵審核制度** - 兒童完成的任務需家長確認後才能領取積分
- [ ] **使用時間提示** - 每日使用超過 30 分鐘彈出提醒
- [ ] **願望清單審核** - 兌換禮物需家長 PIN 確認
- [ ] **成就牆凱臾** - 收集成就章解鎖特別成就（純裝飾性）

### SHOULD（實用功能）
- [ ] **早晨問候系統** - 首次開啟顯示鼓勵話語
- [ ] **每週摘要報告** - 自動生成每週任務完成摘要（家長視角）
- [ ] **習慣追蹤日曆** - 顯示連續達成天數
- [ ] **簡化每日神秘任務** - 每日隨機一個簡單任務（可跳過）

### COULD（可選）
- [ ] **主題裝扮** - 更換 app 視覺主題
- [ ] **證書列印功能** - 達成里程碑可列印證書

### 明確不做（基於用戶要求）
- [x] 戰鬥系統
- [x] Roguelike 模式
- [x] 島嶼建設
- [x] 公會/多人系統
- [x] 連續登入獎勵
- [x] 限量商品倒計時
- [x] 疲勞激勵機制（"再玩 5 分鐘"等）

### 健康提醒機制
```typescript
// 使用超過 30 分鐘提示
const DAILY_LIMIT_MINUTES = 30;

// 達標顯示
if (dailyMinutes >= DAILY_LIMIT_MINUTES) {
  showReminderModal('今日使用時間已達 30 分鐘，建議休息一下！');
}
```

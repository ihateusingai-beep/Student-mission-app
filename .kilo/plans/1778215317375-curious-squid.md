# 島民小英雄 - UX/UI 持續優化計劃

## 現況分析

### 當前架構
- **App.vue**: 1441 行單一檔案處理所有視圖
- **14 個底部導航 tab**: home, tasks, rewards, badges, abilities, pet, wheel, leaderboard, daily, certificates, stats, themes, admin, settings
- **無路由**: 使用 v-if 條件渲染切換內容
- **Tailwind CSS**:漸層背景 + emoji 圖示

### 現有功能地圖
```
首頁 (home)
├── 問候卡 + 任務剩餘提示
├── 環形進度條 (Phase 2)
├── 寵物預覽
├── 家長留言
├── 三格統計 (完成/剩餘/成就章)
├── 每日神秘任務
├── 任務列表 (只顯示4項)
├── 能力展示
└── 最近活動

導航 Tab (14個)
├── 🏠 首頁
├── 📋 清單 (待辨事項)
├── 🎁 禮物 (願望清單)
├── 🏅 成就 (成就牆)
├── 💪 能力

```

## 1. UX 審計：當前摩擦點

### 1.1 導航問題 (高優先級)
| 問題 | 影響 |
|------|------|
| **14 個 tab 過多** | 需要 `overflow-x-auto`，容易誤觸 |
| **功能分組不清** | 獎勵/成就章/證書/排行榜都屬於「成就系統」但分散 |
| **家長/設定層級過深** | 需要 5 次點擊才能進入家長控制台 |

### 1.2 視覺層級問題 (高優先級)
| 問題 | 影響 |
|------|------|
| **標題競爭** | Header + 問候卡 + 統計卡片同時顯示 multiple 數字 |
| **缺少聚焦** | 沒有明確的主要操作入口 |
| **漸層過多** | 每個卡片都是 `bg-gradient-to-r`，視覺噪音大 |

### 1.3 認知負荷問題 (中優先級)
| 問題 | 影響 |
|------|------|
| **資訊過載** | 首頁一口氣展示 10+ 個資訊區塊 |
| **重複資訊** | 三格統計 vs 環形進度條 vs 任備列表都顯示完成度 |
| **術語不一致** | 「積分」「成就值」「XP」混用 |

### 1.4 架構問題 (中優先級)
| 問題 | 影響 |
|------|------|
| **App.vue 過大** | 1441 行，難以維護 |
| **無組件拆分** | 所有 modal 和邏輯都在同一檔案 |

## 2. UI 重構策略

### 2.1 導航精簡方案

**目標：從 14 Tab → 5 Tab**

| 新架構 | 包含功能 | 理由 |
|--------|----------|------|
| 🏠 今日 | 首頁精簡版 (進度 + 當日重點) | 減少決策疲勞 |
| 📋 任務 | 待辨事項完整列表 | 核心功能 |
| 🎁 獎勵 | 願望清單 + 成就章 | 動機系統 |
| 👤 寵物 | 寵物 + 能力值 | 情感連結 |
| ⚙️ 更多 | 排行榜/數據/主題/家長/設定 | 次要功能收納 |

**過渡方案：分階段實行**
1. Phase A: 維持 14 tab，新增「精簡首頁」示範
2. Phase B: 將「能力/證書/統計」整合入「獎勵」頁
3. Phase C: 最終 5 tab 架構

### 2.2 視覺層級優化

**引入 Primary Action Pattern:**
```
首頁佈局原则：
1. 最大面積 = 單一主要操作 (e.g. 任務打卡)
2. 次要資訊折疊/收起
3. 成就感視覺化 (進度環/動畫) 優先於 數字統計
```

**減少視覺噪音策略：**
- 只在需要強調時使用漸層 (e.g. 成就解鎖)
- 統一 Emoji 尺寸，不要 3xl + 4xl 混用
- 建立「卡片層級」共識：普通/重要/主要

### 2.3 減少認知負荷

**術語統一：**
| 舊術語 | 新術語 | 理由 |
|--------|--------|------|
| 積分/成就值/XP | 成就值 | 統一心智模型 |
| 持續努力/連續 | 連續天數 | 更直觀 |
| 獎勵/禮物 | 願望清單 | 目標導向 |

** Progressive Disclosure:**
```
點擊任務 → 查看詳情 → 完成打卡
     ↓
不需要在首頁顯示：能力經驗值、分類統計、活動日誌
```

## 3. 功能增強

### 3.1 簡化核心流程

**早晨流程 (6:00-9:00)**
- 首次開啟 App → 顯示「早晨問候」+ 今日任務預覽
- 快速打卡按鈕 (如果任務簡單)

**晚間流程 (20:00-22:00)**
- 顯示每日摘要卡片 (已完成 X 件事)
- 家長鼓勵訊息優先顯示
- 明日預覽折疊顯示

### 3.2 減少頁面跳轉

**卡片內操作 (In-Card Actions)：**
- 任務卡片：點擊直接打卡，不需要彈出詳情
- 寵物餵食：在寵物預覽卡直接完成

**滑動手勢支援：**
- 左滑任務卡片 → 快速刪除
- 右滑 → 完成打卡

### 3.3 精簡過渡動畫

**減少 animation 種類：**
| 舊 | 新 | 理由 |
|----|----|------|
| animate-bounce | animate-pulse (更柔和) | 減少暈動症 |
| 多種過渡效果 | fade + scale 兩種 | 一致性 |
| 音效 + 動畫 | 可關閉音效，保留視覺 | 減少干擾 |

## 4. 無障礙改進

### 4.1 當前支援
- `prefers-reduced-motion` 已實作
- Emoji 作為圖示 (需校驗螢幕閱讀器)

### 4.2 改進計劃

| 功能 | 實現方式 |
|------|----------|
| **大字模式** | 設定頁增加「大字模式」開關，影響 cards 和 navigation |
| **高對比度主題** | 新增「高對比度」主題選項 |
| **螢幕閱讀器優化** | aria-label 添加到所有 buttons 和 interactive elements |
| **點擊區域** | 所有可點擊元素最小 44x44px (iOS HIG) |
| **減少動態效果** | 預設尊重 `prefers-reduced-motion`，用戶可覆寫 |

### 4.3 多語言支援
- 現有 zh-HK / zh-CN / en 已完整
- 新增功能時確保三語同步更新

### 5.1 追蹤指標

| 指標 | 測量方式 | 目標 |
|------|----------|------|
| **任務完成率** | 每日完成數 / 總任務數 | > 70% |

| **功能使用分佈** | 各 Tab 點擊次數 | 避免頭重腳輕 |
| **完成時間** | 從開啟到完成首個任務 | < 10 秒 |

### 5.2 A/B 測試框架

**測試點：**
1. 首頁佈局：5-tab vs 3-tab

4. 獎勵圖示：Emoji vs 插圖

**實現方式：**
- Firebase Remote Config 控制實驗變數
- 简单实现：localStorage 标记用户参与的实验组

### 5.3 用戶反饋渠道

| 渠道 | 用途 |

## Phase A 詳細實施計劃

### A.1 術語統一 (i18n.js)

**需要標準化的術語：**
| 當前 | 提議 | 影響範圍 |
|------|------|----------|
| 積分 / 成就值 / XP | 統一使用「成就值」 | Header、獎勵商店、統計 |
| 持續努力 | 統一使用「連續」 | Header streak |
| 獎勵 / 禮物 | 統一使用「願望」 | Tab 名稱、頁面標題 |
| 待辨事項 / 任務 | 統一使用「任務」 | 全部 |
| 累計 / 總共 | 統一使用「累計」 | 任務統計 |

**檔案:** `src/utils/i18n.js`

**實作：**
1. 更新 zh-HK, zh-CN, en 三個語言的 keys
2. 確保所有显示文字都通过 `t()` 函数

### A.2 視覺噪音減少

**移除過多彩色漸層：**
```diff
- bg-gradient-to-r from-yellow-400 to-orange-400
+ bg-yellow-50 (統一淺色背景)

- bg-gradient-to-r from-pink-400 to-purple-500
+ bg-purple-50 (統一淺色背景)
```

**保留漸層的場景：**
- 成就解鎖 (金色漸層)
- 任務完成慶祝 (綠色漸層)
- 警告/錯誤提示 (紅色漸層)

**統一 Emoji 尺寸：**
- 統一使用 `text-2xl` (不混用 text-3xl, text-4xl)
- Tab icon 保持 `text-xl`

### A.3 主要操作突出顯示

**首頁改造目標：**
```
改造前：10+ 資訊區塊同時展示
改造後：3 個核心區塊
├── 進度卡片 (環形進度 + 主要 Call to Action)
├── 今日任務列表 (只顯示未完成，最多5項)
└── 寵物/成就精簡版 (點擊進入詳情)
```

**卡片層級定義：**
| 等級 | 使用場景 | 樣式 |
|------|----------|------|
| Primary | 任務打卡/主要操作 | 白色背景 + 陰影 + 左邊框強調 |
| Secondary | 資訊展示 | 灰色背景 |
| Tertiary | 次要資訊 | 透明/白色 |

### A.4 字體大小調整

**當前問題：**
- Header h1: `text-xl`
- 問候語: `text-lg`
- 正文: `text-sm`

**建議調整：**
- 標題統一 `text-lg font-bold`
- 正文統一 `text-base`
- 備註/次要文字 `text-sm text-gray-500`

### A.5 Phase A 驗收標準

- [ ] i18n.js 中術語一致，無混用
- [ ] 首頁卡片從 10+ 減少到 5 以內
- [ ] 漸層使用從 8+ 減少到 3 以內
- [ ] 主要操作按鈕有明確視覺突出
- [ ] `npm run build` 成功

## 8. 成功標準

### 短期 (1 個月)
- 首頁任務完成時間減少 30%
- 導航 tab 滑動不再需要 `overflow-x-auto`
- 用戶可以說出「我今日完成了 X 件事」

### 中期 (3 個月)
- 7日留存率提升至 55%
- 單次使用時長保持在 2-5 分鐘區間
- 家長控制台使用率提升

### 長期 (6 個月)
- App Store 評分 4.5+
- 玩家可以向朋友解釋遊戲核心循環 < 30 秒
- 系統可支持未來功能擴展 (課題/多人模式)

## 9. 風險與緩解

| 風險 | 可能性 | 緩解方案 |
|------|--------|----------|
| 導航改變影響現有用戶習慣 | 高 | Phase A 先做不破壞性改動，提供舊版 option |
| 重構引入 bug | 中 | 每次重構後執行 smoke test |
| 用戶不接受視覺改變 | 低 | 保留主題切換功能 |
| Firebase 依赖复杂度 | 低 | 当前为 localStorage，后续按需迁移 |

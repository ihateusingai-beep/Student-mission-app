# 島民小英雄 - 持續優化計劃

## 現況回顧
Phase 1 已完成（i18n.js 字眼本地化）。接下來需要從戰略文件提取具體功能建議。

---

## 從策略文件提取的關鍵優化建議

### 1. 視覺化進度系統
| 功能 | 優先級 | 說明 |
|------|--------|------|
| 等級進度條 | 高 | 英雄等級 LV1→LV2，顯示 XP 進度 |
| 今日完成環形圖 | 高 | 漸變色（未完成→完成），顯示 X/Y |
| 每週趨勢圖 | 中 | 柱狀圖顯示過去7天完成量 |
| 等級升級動畫 | 中 | 煙火 + 音效 + 徽章展示 |

### 2. 每日流程引導
| 功能 | 優先級 | 說明 |
|------|--------|------|
| 早晨問候語 | 高 | 「早晨！今日有 X 件事等你完成」 |
| 晚間摘要 | 高 | 睡覺前顯示「今日你完成左 N 件事，好叻！」 |
| 明日預覽 | 中 | 顯示明日預計任務，讓學生有心理準備 |

### 3. 情緒與心理支援
| 功能 | 優先級 | 說明 |
|------|--------|------|
| 情緒打卡 | 中 | 每天問「今日心情點？」😊😐😢😤 |
| 成長思維提示 | 低 | 完成失敗任務時顯示「下次一定得！」 |
| 連續努力視覺化 | 高 | 不以排名顯示，以「你已經持續努力 X 天」 |

### 4. 家庭支援系統
| 功能 | 優先級 | 說明 |
|------|--------|------|
| 家長鼓勵留言 | 高 | 家長可在支援台留言，顯示在首頁 |
| 寵物日記 | 中 | 寵物表情反映今日完成度 |
| 週末特別任務 | 低 | 家人活動任務（幫手煮飯、一齊運動） |

## Phase 2 詳細計劃（功能微調）

### 2.1 視覺化進度條（預計 4-6 小時）
- [ ] 在首頁頂部添加「今日完成度」環形進度條
- [ ] 進度條顏色漸變：灰色 → 黃色 → 綠色
- [ ] 顯示文字「今日已完成 3/5 件事」
- [ ] 添加等第 LV 顯示（當前 LV + XP 進度條）

### 2.2 完成慶祝動畫（預計 2-3 小時）
- [ ] 完成任一事項後顯示「+N 成就值」上浮動畫
- [ ] 完成所有事項後顯示煙火動畫 + 「好嘢！今日全部完成！」
- [ ] 添加成功音效（可關閉）

### 2.3 每日摘要功能（預計 3-4 小時）
- [ ] 晚間首次打开时显示当日总结
- [ ] 顯示「今日完成 X 件事，共獲得 Y 成就值」
- [ ] 若有家長留言則一併顯示

### 2.4 家長鼓勵留言（預計 2-3 小時）
- [ ] 家長支援台增加「留言鼓勵」輸入框
- [ ] 留言保存在 localStorage
- [ ] 首頁頂部顯示最新家長留言（如有的話）

## Phase 3 詳細計劃（系統重構）

### 3.1 App.vue 重構（預計 8-12 小時）
將 1300+ 行的 App.vue 拆分為獨立組件：
- `components/HomeView.vue` - 首頁（進度條、精靈、家長留言）
- `components/QuestList.vue` - 待辨事項列表
- `components/RewardStore.vue` - 願望清單
- `components/BadgeWall.vue` - 成就牆
- `components/ParentConsole.vue` - 家長支援台
- `components/Settings.vue` - 設定頁面
- `components/DailySummary.vue` - 每日摘要彈窗

### 3.2 寵物系統升級（預計 4-6 小時）
- [ ] 寵物表情根據今日完成度變化
- [ ] 完成所有事項後寵物出現開心表情
- [ ] 達成特定目標解鎖新寵物外觀

### 3.3 任務模板系統（預計 3-4 小時）
- [ ] 提供早晨/課後/晚間任務範本
- [ ] 一鍵添加預設任務到清單

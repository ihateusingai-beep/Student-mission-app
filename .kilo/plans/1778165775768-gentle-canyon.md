# Code Review: 島民小英雄 (Island Mission Hero)

## Project Overview

**Type**: Vue 3 + Pinia + Vite SPA (PWA-ready)
**Purpose**: HK secondary school gamified learning app
**Size**: ~1,300 lines in App.vue, 2 stores, 3 utilities

---

## 1. Architecture Assessment

### Strengths
- Clean separation: stores (business logic) vs utils (storage/i18n/sound) vs components
- Pinia for state management with good computed properties
- LocalStorage abstraction layer in `storage.js` for persistence
- i18n system with 3 languages (zh-HK, zh-CN, en)
- PWA manifest present (`public/manifest.json`)

### Issues
- **Single-file component**: `App.vue` at 1,314 lines is too large - should split into smaller components
- **No Vue Router**: All navigation via `currentTab` state in one component
- **Firebase imported but not used** in visible code (`package.json` has firebase)
- **Inconsistent naming**: Mixed Cantonese (e.g., `🐾 寵物`) and English in code

---

## 2. Bug Risks Found

### 🔴 Critical

1. **`petState` initialization mismatch** (`game.js:191-203`)
   - `loadPet()` may return `{ id: null }` but `petState.value.id` check at line 193 will fail
   - Pet may not load correctly from storage on refresh

2. **Streak calculation off-by-one** (`storage.js:256-269`)
   - Uses `yesterday.toDateString()` but `this.today` same day check may reset streak incorrectly
   - If user completes task at 11:59pm and returns at 12:01am, streak might reset

3. **Missing `totalCount` in `addTask`** (`user.js:174-186`)
   - `addTask` doesn't set `totalCount` property, but other functions assume it exists (e.g., `App.vue:842`)

4. **`logActionName()` returns English for Cantonese keys** (`App.vue:917-925`)
   - Map uses `t()` which returns translated string, but direct strings like `'解鎖徽章'` won't match English translations

### 🟡 Medium

5. **`completeDailyMission` doesn't check task completion state** (`App.vue:1230-1238`)
   - Completes mission even if no tasks done - no validation

6. **Leaderboard rank always returns 0** (`game.js:545-547`)
   - `leaderboardRank` computed always returns 0, not calculating actual rank

7. **No error handling in `importData`** (`App.vue:1124-1139`)
   - If localStorage quota exceeded, import silently fails

8. **Pet decay timer persists in memory** - no cleanup on unmount

9. **`resetAll` clears points to 0 but doesn't reset streak properly** (`user.js:268-274`)

### 🟢 Minor

10. **Hardcoded `10` points cost for pet feeding** (`App.vue:1204`) - should use constant
11. **Missing `newReward.icon` default** in `addNewReward` - uses placeholder but doesn't reset properly
12. **`exportCSV` uses wrong field names** (`App.vue:1106-1112`) - `log.type` and `log.text` don't exist on log objects

## 3. New Feature Suggestions

### High Value

1. **Cloud Sync (Firebase)**
   - Currently firebase is a dependency but unused
   - Could sync user data across devices for HK students who use multiple devices

2. **Task Recurrence Patterns**
   - Add weekly/daily recurring task templates
   - Currently only `totalCount` tracks lifetime completions, no weekly view

3. **Social/Team Features**
   - Team system exists in code but no UI to join/create teams
   - `teamCode`, `teamMembers` defined but never rendered

4. **Push Notifications**
   - `ReminderManager` exists but only uses `setTimeout` for reminders
   - Real push notifications would improve engagement

### Medium Value

5. **Animated Confetti on Badge Unlock** - visual reward feedback

6. **Pet Sickness/Status Effects**
   - If hunger/happiness drops below 20, pet shows sad state
   - Currently only grays out buttons

7. **Seasonal Events System**
   - Special tasks/rewards during school holidays

8. **CSV Import for Tasks** - parents could bulk-add tasks via spreadsheet

### Low Effort Quick Wins

9. **Add "Copy PIN" functionality** in admin console
10. **Show "days until reward available"** in rewards store
11. **Dark mode toggle** alongside theme system

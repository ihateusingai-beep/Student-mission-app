## 策略調整

單人開發 + 3個月 + React Native 重寫 = 必須採用**最小可行產品（MVP）策略**

### 核心原則
1. **不做過度工程** - 每個功能必須有清晰的家長/兒童價值
2. **移動優先** - 兒童用平板/手機，Touch 友好設計
3. **離線優先** - localStorage 作為主要存儲，Firebase 作為可選同步
4. **可愛優先** - 兒童市場，視覺吸引力 > 功能深度
